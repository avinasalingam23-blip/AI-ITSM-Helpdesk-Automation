# Outlook synchronisation troubleshooting

Scope: Outlook inbox, calendar or sent items are not synchronising. Owner: Desktop Support. Approved demo article, reviewed 2 November 2026.

First confirm that the laptop has a working internet connection. Open the organisation's webmail page through your usual trusted bookmark and check whether new mail appears there. If webmail is current but the desktop client is stale, the issue is likely local to Outlook. If both are stale, contact Messaging Support with the time of the last received message.

In Outlook, inspect the connection indicator and make sure Work Offline is disabled. Select Send/Receive All Folders and allow time for the synchronisation to complete. Close and reopen Outlook if it remains disconnected. Check that the system clock is correct. If Outlook asks for sign-in, use the normal corporate sign-in window and complete multi-factor authentication. Never put passwords or verification codes into chat.

For a persistent problem, record the affected folder, error text, Outlook version and whether webmail works. Ask Desktop Support to review the profile before rebuilding it. Do not delete a mailbox, local data file or cached profile without an approved backup and an agent's supervision. This prototype provides knowledge guidance only; it does not access mailboxes, clear caches or restart applications. Escalate with the diagnostic details if these checks do not help.
