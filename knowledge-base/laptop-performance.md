# Slow laptop and performance checks

Scope: a laptop is slow, freezes, overheats or responds poorly. Owner: Desktop Support. Approved demo article, reviewed 2 November 2026.

Save current work first. Open Task Manager and observe CPU, memory and disk usage without ending unfamiliar processes. Close unused applications through their normal menus. Check available disk space using system settings. If updates are pending, schedule a restart at a suitable time after saving work. Keep vents clear and use the laptop on a firm surface.

Record whether the slowdown affects every application or a single application, when it began, and whether the laptop is unusually hot. Include recent approved software changes in an incident. Do not disable security tools, edit the registry, delete system directories or run scripts copied from an unknown website. A slow device might need hardware inspection or a managed update rather than an automated cleanup.

Desktop Support handles recurring freezes, disk errors and suspected hardware faults. This prototype has no approved cleanup or service-restart action. It can provide guidance and open a ticket, while avoiding commands that would affect real files. For an unresponsive laptop, seek support before a forced shutdown when unsaved work is at risk. A widespread slowdown across the office should be reported as multiple-user impact.
