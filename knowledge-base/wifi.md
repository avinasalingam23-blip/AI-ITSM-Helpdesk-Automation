# Corporate Wi-Fi connectivity

Scope: a laptop cannot connect to corporate Wi-Fi or the wireless connection drops. Owner: Network Support. Approved demo article, reviewed 2 November 2026.

Check that airplane mode is off and Wi-Fi is enabled. Select the approved corporate wireless network from the normal operating-system network menu. Move closer to a known access point and compare connectivity with another device if possible. Reconnect once through the normal network menu. Do not join an unfamiliar network that imitates the corporate network name.

If the network connects but pages do not load, check whether the problem affects only the laptop or other colleagues nearby. Note the office location, approximate time and the exact error. A password or certificate prompt should be handled through the trusted corporate sign-in flow. Never disclose credentials in a ticket or accept an unexpected certificate without support review.

Network Support can investigate an access point outage, DHCP issue or certificate deployment problem. This prototype cannot reset a network adapter or change corporate network settings. It supplies checks and can create an incident. Escalate after the basic connectivity checks fail, and use an approved wired connection if one is available. A wider outage is treated as higher impact according to the ticket priority policy.
